# GovPilot AI

Autonomous Public Service & Bureaucracy Execution Agent built for **IDEA//FORGE Online Hackathon** (Track 1: Civic Pulse, Digital Governance & Public Information).

## Overview
GovPilot AI helps citizens and students complete online public service forms (such as scholarship applications, transit pass renewals, and subsidy claims) by mapping profile fields dynamically, recovering from formatting/validation errors, pausing for human OTP/CAPTCHA checks, and generating a submission receipt.

## Contents
- `index.html`, `styles.css`, `app.js`: Interactive web MVP console demonstrating end-to-end execution, validation recovery, OTP checkpointing, and receipt generation.
- `agent_playwright.py`: Reference Playwright automation structure for live browser form filling.
